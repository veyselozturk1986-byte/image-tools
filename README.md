# PrivacyConvert Sovereign OS ⚡

A 100% client-side, air-gapped privacy and utility suite built for secure document management, encryption, and data redaction with **0 KB external network traffic**.

### Key Features
* 🛡️ **Zero Cloud Telemetry:** All processes (OCR, AES-256, PDF merging, PII redaction) run locally in your browser.
* 🔒 **Air-Gapped Security:** Works completely offline once loaded.
* 💽 **Advanced Tools:** OPFS encrypted storage, WebAuthn passkeys, and P2P WebRTC file sharing.
