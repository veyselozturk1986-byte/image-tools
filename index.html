📚 Frequently Asked Questions (FAQ)

Q: What technical conditions are required for all tools to work fully functionally?

A: A Secure Context is required. For advanced browser storage and authentication APIs like OPFS (Encrypted Disk) and WebAuthn (Passkey) to function without errors, the application must be run via a local server such as localhost or HTTPS rather than directly opening the file via file://.

Q: What exactly is the "Air-Gapped" security feature?

A: The Air-Gapped architecture ensures that the system runs 100% on the client side with 0 KB of outbound network traffic. All processed texts, encrypted files, OCR extractions, and scan reports remain entirely within your browser session. No data is sent to external servers, uploaded to the cloud, or leaked elsewhere.

Q: Can the application be used completely offline?

A: Yes. Heavy libraries like pdf.js and tesseract.js are cached in your browser via a Service Worker upon initial load. Once cached, the application can perform all operations locally even in completely isolated (air-gapped) environments without an internet connection.
